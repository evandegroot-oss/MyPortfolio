# Viewport Sizes

The website uses three CSS files for different screen sizes:

- Phone: 480px and below
- Tablet: 481px–960px
- Full screen: 960px and above

These dimensions were chosen to provide different layouts for phones, tablets, and larger computer screens. The phone size is designed for smaller screens, the tablet size is for medium-sized screens, and the full screen size is for larger monitors. Using separate CSS files allows the website to resize and adjust for each type of device.

# Gradients

The website uses a regular linear gradient for the header and footer. (#012840, #11468C)

The website uses an angled linear gradient on the navigation buttons when the mouse hovers over them. (45deg, #F2522E, #F29580)

# Color Scheme

The color scheme I used was from putting a screenshot of the Ontario Tech website into Adobe Color to find similar colors.

Color scheme hexadecimal values: #11468C #012840 #F2522E #F29580 #F2F2F2

The blue colors are mainly used for the header, footer, and navigation, while the orange colors are used for the accents.
